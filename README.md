# 名城大学 情報工学科 履修登録システム

## プロジェクト概要

名城大学情報工学部情報工学科の学生専用の履修登録支援Webシステムです。先輩や同級生の履修情報を参考にしながら、最適な履修計画を立てることができます。

## 主な機能

### 1. 履修情報共有機能
先輩や同級生の履修経験を共有・閲覧できる機能です。

**主な機能：**
- 履修情報の投稿（偽名での投稿可能）
- 学年・学期・科目区分でのフィルタリング
- キーワード検索（科目名、教員名、コメント）
- 難易度・満足度の評価表示
- 並び替え機能（新しい順、古い順、満足度順、難易度順）

**投稿できる情報：**
- ニックネーム（偽名）
- 学年（1〜4年生）
- 学期（前期/後期/通年）
- 科目名
- 教員名
- 科目区分（必修/選択必修/選択）
- 単位数
- 難易度（1〜5の5段階評価）
- 満足度（1〜5の5段階評価）
- コメント（授業の感想・アドバイス）

### 2. 履修登録機能
自分の履修科目を時間割形式で管理できる機能です。

**主な機能：**
- 時間割表示（月〜金、1〜5限）
- 学期別表示（前期/後期/通年）
- 科目の追加・削除
- 単位数の自動計算
  - 総単位数
  - 必修単位数
  - 選択必修単位数
  - 選択単位数
- 科目区分別の一覧表示
- 時間割の重複チェック

**登録できる情報：**
- 科目名
- 教員名
- 曜日・時限
- 学期（前期/後期/通年）
- 科目区分（必修/選択必修/選択）
- 単位数
- 教室

### 3. シラバス検索機能
大学の授業シラバスを検索・閲覧できる機能です。

**主な機能：**
- キーワード検索（科目名、教員名、授業概要）
- 詳細フィルタリング
  - 対象学年
  - 開講学期
  - 科目区分
  - 曜日・時限
  - 単位数
- シラバス詳細表示
  - 授業コード
  - 授業概要
  - 到達目標
  - 評価方法
  - 教科書
  - キーワード

## 使い方

### 初回アクセス時
1. ブラウザで `index.html` を開きます
2. トップページから各機能にアクセスできます

### 履修情報を投稿する
1. ナビゲーションから「履修情報共有」をクリック
2. 投稿フォームに必要事項を入力
3. 「投稿する」ボタンをクリック

### 履修情報を検索・閲覧する
1. 「履修情報共有」ページで、フィルターやキーワード検索を利用
2. 並び替えで表示順を変更可能
3. レビューカードで他の学生の投稿を閲覧

### 履修登録をする
1. ナビゲーションから「履修登録」をクリック
2. 学期を選択
3. 時間割上の「科目を追加」ボタンをクリック
4. 科目情報を入力して「追加」
5. 登録単位数が自動的に計算されます

### シラバスを検索する
1. ナビゲーションから「シラバス検索」をクリック
2. 検索キーワードを入力、または詳細フィルターを使用
3. 検索結果から科目をクリックして詳細を表示

## RESTful API エンドポイント

### 履修情報共有
- `GET tables/shared_course_reviews?limit=100` - 投稿一覧取得
- `POST tables/shared_course_reviews` - 新規投稿作成

### 履修登録
- `GET tables/my_courses?limit=100` - 登録科目一覧取得
- `POST tables/my_courses` - 科目追加
- `DELETE tables/my_courses/{id}` - 科目削除

### シラバス
- `GET tables/syllabus?limit=100` - シラバス一覧取得
- `GET tables/syllabus/{id}` - シラバス詳細取得

## 注意事項
